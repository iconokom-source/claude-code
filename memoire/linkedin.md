# LinkedIn — style de Louis

Géré dans Never Boring AI (toujours appeler get_context, list_memory, list_anecdotes avant d'écrire).

- 5 posts par semaine, publication par défaut à 9h (Europe/Paris). Objectif : mix notoriété / leads / réseau.
- Piliers : problèmes clients décortiqués, cas clients et résultats, expertise actionnable, coulisses de l'équipe,
  vendre sans forcer, actualités du marché, l'offre.
- Ton : direct, inspirant, storyteller, de l'humour ; emojis rares ; longueur moyenne ; une idée par post ; opinion d'abord ; chiffres concrets.
- **Fin de post : pas de question finale** (il la supprime systématiquement). Finir sur le bénéfice concret,
  une affirmation tranchée, ou un renvoi vers les DM / « en com' » quand il y a une ressource.
- Nuancer le hook (« sûrement », conditionnel) quand l'affirmation repose sur son expérience.
- Supprimer les phrases qui reformulent ce que le lecteur a déjà compris ; pas de justification négative (« pas par X »).
- Vocabulaire : « créas » plutôt que « livrables » ; « douleurs de ses clients » ; « garanties », « avantages sur la concurrence » ;
  nommer le domaine (« copywriting », « positionnement ») plutôt que « le vrai travail ».
- Petite touche perso entre parenthèses quand il mentionne l'équipe.
