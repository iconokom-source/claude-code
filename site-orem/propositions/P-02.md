# P-02 — Préchargement des pages projets : prêt à appliquer (en attente d'accord)

**Aujourd'hui** : le script global de la modale télécharge et analyse, dès le chargement, la page de **chaque** carte présente : 9 pages sur l'accueil (~410 Ko de HTML décompressé), 18 sur Réalisations, 3 sur À propos, 4 sur Lille. Même si le visiteur n'ouvre aucune carte.

**Proposition** : charger la page d'une carte seulement quand le visiteur montre son intention (survol, focus clavier, toucher). Même taille de code (on remplace le bloc, on n'en ajoute pas).

**Mesure (simulation sur agence-orem.fr, 2026-10-21)** :

| Page | Pages préchargées au chargement | Ouverture de la modale (ordinateur / mobile) |
|---|---|---|
| Accueil | 9 → 0 | 41 → 83 ms / 4 → 207 ms |
| Réalisations | 18 → 0 | 3 → 4 ms / 5 → 270 ms |
| À propos | 3 → 0 | 27 → 7 ms / 2 → 104 ms |

Flèches : inchangées (~550–800 ms, dominées par l'animation de 250 ms et le réseau). Aucune erreur JS.

**Contrepartie** : sur mobile, l'ouverture peut prendre 0,1 à 0,3 s de plus (le toucher laisse peu d'avance).

**Application** : dans le code global (footer du site), remplacer exactement le contenu de `P-02-avant.js` par `P-02-apres.js` (1 occurrence), vérifier octet par octet que le reste du bloc est identique, publier sur le sous-domaine, relancer `tests/prechargement-p02.mjs`, `modale-seo.mjs`, `fonctionnel.mjs`. Retour arrière : opération inverse.
