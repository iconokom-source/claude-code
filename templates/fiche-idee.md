# Format obligatoire d'une fiche idée

Chaque idée produite par `/content-manager` suit exactement ce format.

```markdown
### [ID] Titre de travail (thèse en une phrase)

| Champ | Valeur |
|---|---|
| Pilier | P1 à P5 |
| Objectif final | NOTO / AUTO / LEAD / CONV / NURT / RECR : + résultat attendu concret |
| Persona cible | CMO scale-up / Fondateur / Dir. com / Pairs |
| Format recommandé | Texte / Carrousel / Vidéo face cam / Sondage / Document PDF |
| Fenêtre de publication | Maintenant (actu chaude) / Sous 2 semaines / Intemporel |
| Score | Impact x /5 · Preuve x /5 · Fraîcheur x /5 · Fit Louis x /5 = total /20 |

**Insight de départ (pourquoi maintenant)**
Ce qui a été observé, avec la source : lien + date, ou transcript Fireflies (date, type de call), ou stat client anonymisée.

**Croisement de sources**
Quelles autres sources confirment : ex. "Tendance US (Kevin Indig, 12/09) + objection entendue sur 3 calls + CTR en baisse sur 4 sites clients".

**Angle traité**
Type d'angle (voir liste) + la thèse précise que Louis défend. Ce qui rend ce post différent de ce que tout le monde publiera.

**Hooks (3 propositions)**
1. ...
2. ...
3. ...

**Squelette**
- Accroche
- Tension / problème
- Preuve (chiffre, verbatim, exemple)
- Lecture de Louis
- Chute + CTA

**CTA**
Cohérent avec l'objectif final.

**Déclinaisons et recyclage**
| Variante | Angle différent | Format | Quand |
|---|---|---|---|
| V1 | ... | ... | J+0 |
| V2 | ... | ... | J+45 |
| V3 | ... | ... | J+90 |
| V4 (mise à jour) | Même thèse, nouvelles données | ... | J+180 |

**Date de péremption** : date après laquelle l'idée n'a plus de sens (ou "aucune").
```

## Bibliothèque d'angles

| Code | Angle | Exemple de thèse |
|---|---|---|
| A1 | Prédiction US → FR | "Ce qui arrive aux agences US depuis mars arrivera en France au printemps." |
| A2 | Contrarian | "Refaire son site tous les 3 ans est une erreur. Voici pourquoi." |
| A3 | Étude de cas chiffrée | "Même trafic, x2 démos : les 3 changements." |
| A4 | Objection retournée | Verbatim prospect → réponse argumentée |
| A5 | Coulisses / décision | "Pourquoi on a refusé un projet à 40 k€." |
| A6 | Framework propriétaire | Méthode nommée en étapes, réutilisable |
| A7 | Erreur / mea culpa | "L'erreur qui nous a coûté 3 semaines." |
| A8 | Décryptage d'actu | Annonce Webflow / Google + ce que ça change concrètement |
| A9 | Comparatif honnête | Webflow vs Framer vs WordPress pour tel cas |
| A10 | Mythe vs réalité | Croyance du marché démontée par la data |
| A11 | Checklist / ressource | Lead magnet déguisé |
| A12 | Données agrégées | "On a analysé 15 sites clients : voici ce qu'on voit." |

## Grille de score

- **Impact** : le sujet touche-t-il une douleur ou un enjeu business de l'ICP ? (5 = budget / pipeline / risque)
- **Preuve** : 1 = opinion seule ; 3 = une source ; 5 = 2+ sources croisées dont une donnée propre (Fireflies ou clients)
- **Fraîcheur** : 5 = actu < 7 jours ou signal US pas encore traité en France
- **Fit Louis** : légitimité d'ICONOKOM à le dire + alignement pilier

Seuil de publication recommandé : **14/20**.
